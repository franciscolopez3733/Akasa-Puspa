# Daksa

Código de honor *ksatrya*. Literalmente «valor».

## Normas principales

| Norma | Detalle |
|-------|---------|
| Prohibiciones | Robar, mentir, romper juramentos |
| Obligaciones | Vengar la afrenta de un perjuro de forma gratuita |
| Frente a la muerte | Un ksatrya no teme morir en combate |
| Premio final | ***Pitrloka***: éxtasis donde se rememoran las hazañas |
| Traición al código | La mayor deshonra |

## Origen histórico

Escrito por el **Samiti** hace ~1.400 años tras contactar con el Imperio (los ksatrya sufrían deserciones crónicas lejos de casa). Complementado por la ley marcial ***Farman***.
